Minimalistic Complexity

We believe richness and complexity should not be inversely proportional. An interface should become more capable without becoming more difficult to understand.

In mathematics, a simple function can produce extraordinary complexity beneath the surface. We believe interfaces should work the same way.

The system can be deeply complex while the experience remains simple, intuitive, and instinctive.
